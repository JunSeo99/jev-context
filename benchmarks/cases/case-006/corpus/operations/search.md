# 검색 인덱스 점검 절차
승인 상태: 2026-07-10 확정

ap-northeast 지역의 전체 텍스트 검색만 일시 중지한다.
문서 열기, 편집, 저장 및 파일 다운로드는 계속 가능하다.
점검 중 만든 문서는 검색 재개 후 순서대로 인덱싱한다.
검색 재개 뒤 최신 문서 반영에는 최대 20분이 걸릴 수 있다.
고객이 편집을 중지하거나 별도로 백업할 필요는 없다.

## 시작 조건
대기 중인 색인 작업 수를 기록한 뒤 작업자를 정지한다.
노드 검색-3을 교체하고 segment-v7을 검증한다.
내부 노드명과 인덱스 이름은 고객 공지에 쓰지 않는다.
[게시 기준](../docs/writing.md)의 최종 확인 규칙을 따른다.

## 실패 시
검증이 실패하면 이전 색인으로 되돌리고 상태 페이지를 갱신한다.
작업 종료 시간은 목표이며 복구 검증 전 완료라고 쓰지 않는다.
점검 종료 후 지연 작업이 사라졌는지 확인한다.
