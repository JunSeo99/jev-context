# 7월 검색 작업 문의 준비
배포용: 지원팀 내부

7월 18일 02:00~02:30 Asia/Seoul에 검색 기능만 점검한다.
열기, 편집, 저장, 다운로드는 사용할 수 있다.
고객은 평소처럼 작업해도 되며 별도 백업은 필요하지 않다.
검색 재개 뒤 새 문서가 나타날 때까지 최대 20분을 안내한다.
동일 내용은 확정된 search 작업 절차에서 가져왔다.

## 답변
점검이 길어지면 상태 페이지의 15분 간격 업데이트를 안내한다.
확정되지 않은 완료 시각을 개별 고객에게 약속하지 않는다.
담당 회전조만 배정되었고 공개 승인된 실명은 등록되지 않았다.

## 별도 문의
검색 필터 사용법은 도움말의 고급 검색 항목을 안내한다.
저장 실패 문의는 이 점검과 별도로 조사한다.
청구 내역 문의는 결제 지원 대기열로 옮긴다.
