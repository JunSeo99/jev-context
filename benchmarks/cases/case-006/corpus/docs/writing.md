# 외부 공지 작성 기준
현행: 2026-02-01

날짜와 시간대는 축약 없이 함께 표시한다.
영향을 받는 기능과 계속 가능한 기능을 모두 적는다.
내부 호스트명, 노드 식별자, 장애 우회 명령은 공개하지 않는다.
검증이 끝나기 전에는 정상화 완료를 약속하지 않는다.
예상 종료 시간은 예정이라고 표현한다.

## 문의
운영 문의 경로는 상태 페이지와 support@example.test다.
공개 연락처에 개인 휴대전화나 내부 당직 별칭을 넣지 않는다.
담당자 이름은 해당 공지용으로 승인된 경우에만 쓸 수 있다.

## 표현
점검 사유는 고객이 이해할 수 있는 기능 수준에서 설명한다.
영향이 없는 고객에게 추가 행동을 요구하지 않는다.
사과 문구를 여러 문단에서 반복하지 않는다.
