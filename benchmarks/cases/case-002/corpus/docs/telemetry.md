# 이벤트 수집 공통 규칙
상태: 현행

인증 단계의 이벤트에는 원문 URL이나 query 값을 저장하지 않는다.
거부 이유 코드와 attempt 식별자만 기록한다.
ticket, sid, return_to 원문은 오류 메시지에서도 제외한다.
이 규칙은 고객 문의를 위한 수동 재현 로그에도 적용한다.

## 전달 경로
클라이언트 이벤트는 배치로 수집한다.
서버 이벤트의 시각은 UTC를 사용한다.
이벤트명이 바뀌면 대시보드 담당자에게 알려야 한다.

## 사무 기기
회의실 화면의 브라우저는 퇴실 전에 로그아웃한다.
테스트 세션은 개인 계정과 분리해 만든다.
화면 녹화에는 임시 계정만 사용한다.
