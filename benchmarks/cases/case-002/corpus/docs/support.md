# 로그인 문의 대응
갱신: 2026-05-16

잘못된 복귀 주소는 /workspace로 보내며 인증 성공은 취소하지 않는다.
안내문에는 다시 원하는 화면을 열어 달라고 설명한다.
북마크 예외는 navigation 문서와 현재 설정을 함께 확인한다.
tenant가 다른 portal 북마크는 허용하지 않는다.

## 조사 자료
문의 시 발생 시각과 attempt 식별자를 받는다.
고객에게 로그인 URL 전체를 보내 달라고 요청하지 않는다.
전체 북마크 사용량이나 tenant별 분포는 수집하지 않았다.
이전 주소를 자주 쓰는 고객 수는 이 폴더에서 알 수 없다.

## 별도 문제
비밀번호 재설정 메일의 만료 시간은 20분이다.
메일이 늦어지면 새 링크를 여러 번 만들지 않도록 안내한다.
