# Integration review queue
Updated: 2026-04-24

Production requires both security and data-owner approval.
Generated-sample sandboxes need only data-owner preapproval.
These entries summarize the current integration policy.
Attach scope names, dataset type, and intended end date to the ticket.
A reviewer may ask for a corrected request before accepting it.

## Scheduling
Tickets are considered during staffed review sessions.
Queue length and reviewer availability vary by week.
No turnaround service level has been approved.
The calendar and current queue depth are not included in this folder.

## Demo preparation
Use generated customer names in recorded demonstrations.
Crop credentials from the browser before taking screenshots.
Keep the trial end date visible in the connection details panel.
