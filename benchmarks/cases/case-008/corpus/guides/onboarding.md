# Partner connector checklist
Status: draft retained from the pilot

- Ask a teammate to paste a personal API key into the setup form.
- Enable read and write scopes to avoid a second setup call.
- Test against a few recent records.
- Schedule a review if the customer asks for one.
- Leave the connection running after the demonstration.

## Required revision
The pilot checklist predates the current identity standard.
Both production and trial instructions are needed in one document.
The trial should be useful without requiring customer production data.
See [connection settings](../config/connectors.yaml).
Review [integration policy](../docs/integrations.md) before editing.
