# Connector pilot notes
Archived: the pilot ended before the April policy

Pilot staff used personal keys for a single internal workspace.
Read and write scopes were bundled in the first provider application.
Trials had no automatic expiry while the scheduler was under test.
A two-day review turnaround was a planning assumption, not an agreement.
These shortcuts were not approved for external onboarding.

## Interface notes
The provider icon now appears next to connection status.
Retry counters were hidden from the setup wizard.
A test-success message is separate from launch approval.
The connection list sorts by most recently updated.
