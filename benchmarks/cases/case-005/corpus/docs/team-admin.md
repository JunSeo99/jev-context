# 팀 관리자 안내
업데이트: 2026-06-20

역할을 바꾸면 해당 사용자의 role_epoch가 증가한다.
이전 role_epoch로 저장한 보고서는 이후 요청에 쓰지 않는다.
이 동작은 reporting 문서의 캐시 계약을 구현한다.
역할 변경 API가 성공한 뒤에 화면의 권한 표시를 갱신한다.

## 운영 점검
지원 가장 세션으로 성능을 측정하면 캐시 효과를 볼 수 없다.
실제 요청 빈도와 사용자별 월 조회 분포는 아직 수집하지 않았다.
적중률 측정 계획은 있지만 측정 결과는 이 폴더에 없다.
월마감 작업은 보고서 데이터 변경 이벤트를 발행한다.

## 팀 구성
초대 메일은 7일 뒤 만료된다.
초대 취소는 기존 사용자의 역할을 바꾸지 않는다.
부서명 변경은 보고서 금액을 수정하지 않는다.
