# 실적 보고서 조회 계약
현행: 2026-06-18

보고서는 team_id, month, viewer_id에 따라 달라진다.
관리자는 팀 전체를 보고 일반 구성원은 본인 행만 본다.
캐시 키에는 team_id, month, viewer_id, role_epoch, key_version을 넣는다.
캐시 TTL은 reports 설정의 ttl_seconds를 따른다.
키 변경은 기존 키를 재사용하지 않는 방식으로 배포한다.

## 무효화
실적 행이 바뀌면 해당 팀과 월의 캐시를 모두 무효화한다.
역할 변경 시 role_epoch를 증가시켜 이전 권한의 값을 재사용하지 않는다.
관리자 역할을 잃은 사용자는 다음 요청부터 일반 구성원 결과를 받는다.
[공통 조회 규칙](requests.md)은 캐시 적중 여부와 무관하게 적용한다.

## 표시
마감된 월에는 수정 버튼을 숨긴다.
금액은 원 단위 정수이며 음수도 허용한다.
합계가 0인 보고서도 정상적인 조회 결과다.
