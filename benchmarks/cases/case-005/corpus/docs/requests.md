# 공통 조회 규칙
적용 범위: 모든 서버 응답

권한 검사는 캐시를 읽기 전에 수행한다.
탈퇴했거나 비활성화된 사용자는 캐시 값이 있어도 거부한다.
가장 중인 지원 세션은 공유 캐시를 읽거나 쓰지 않는다.
지원 세션의 응답에는 Cache-Control: no-store를 설정한다.
관리 목적의 가장은 고객 본인의 접근 권한을 확대하지 않는다.

## 장애 처리
캐시 장애는 원본 조회로 우회할 수 있다.
권한 저장소 장애는 접근 허용으로 우회할 수 없다.
오류 화면에는 재시도 버튼과 요청 식별자를 표시한다.

## 탐색 UI
마지막으로 선택한 탭은 브라우저에 보관한다.
탭 이름은 계정별 언어 설정으로 번역한다.
즐겨찾기는 서버 측 보고서 내용에 영향을 주지 않는다.
